# 0.0.4.0 release notes — draft

> Draft for the upcoming release. `0.0.4.0` has not been tagged, published, or
> submitted to AMO. The current stable release remains `v0.0.3.0`.

## Highlights

- First shared Chromium and Firefox release train.
- One current-site workflow: **Auto**, **Proxy**, or **Direct**, with exact-host
  and domain-with-subdomains scope.
- A compact popup for daily routing and a consistent Options structure for
  automatic routing, site rules, proxy connections, maintenance, advanced
  settings, and product information.
- User-configured HTTP, HTTPS, SOCKS4 and SOCKS5 proxies, including local proxy
  authentication without displaying a stored password again.
- Explicit integrations for local Tor service, Tor Browser and WARP endpoints.
- Toolbar A/P/D/OFF/EXT states, connection checks, sanitized diagnostics, and
  actionable protection/control notifications.
- English and Russian user interfaces.

## Firefox support

Firefox 154+ uses the same Apply, Clear and current-site workflow as Chromium.
Its automatic routing uses the verified Anticensority dataset packaged with the
extension, so the first Apply does not need to download routing data.

Firefox also restores an active configuration after event-page recreation and
blocks protected routing when recovery, private-window permission, or proxy
ownership is lost. When every automatic proxy candidate fails, Firefox stops
the request instead of using Chromium's possible terminal Direct fallback. This
is an intentional safety/availability difference.

## Installation paths

- **Chromium:** download the published Chromium ZIP, verify SHA-256, extract it,
  enable Developer mode and choose Load unpacked.
- **Firefox:** use only the future AMO listing or Mozilla-signed XPI. An unsigned
  reviewer XPI is not a normal end-user release.

Final download and AMO links will be added only after publication. This draft
must not be used as evidence that the release already exists.

## Known limitations

- Firefox remote provider-data updating is disabled for this release candidate:
  the production signed update channel is not configured. The packaged trusted
  dataset remains available and usable.
- Chromium PAC and Firefox declarative routing have the same user workflow but
  different browser-level failure semantics; Firefox intentionally fails closed
  after proxy-chain exhaustion.
- Firefox Apply requires private-window access because Firefox proxy settings
  are global. Clear remains available after access is revoked.
- Tor, Tor Browser and WARP must already be installed, running and listening on
  the configured local endpoints; the extension does not start or discover
  them.
- The extension is not a VPN or an anonymity guarantee. A selected proxy sees
  destinations and traffic within its protocol role.
