# 0.0.4.0 published-release reference

Version `0.0.4.0` was published on 2026-09-18 as the first shared Chromium and
Firefox release:

- [GitHub Release](https://github.com/aVitomin/runet-censorship-bypass-mv3/releases/tag/v0.0.4.0)
- tag target: `7c0c64c3e6bf915d50be01f9f3e5c049a4bbe2a4`
- release-tested: Google Chrome, Microsoft Edge, Brave, and Firefox 154+
- expected compatible but not separately tested: Yandex Browser, Opera,
  Vivaldi, and other suitable modern Chromium browsers with the required MV3
  APIs

The public GitHub Release notes are the authoritative user-facing notes. This
file remains as a compact repository reference for the release boundary.

Firefox remote provider-data updating is disabled in `0.0.4.0`; the trusted
packaged routing dataset remains usable. Firefox intentionally fails closed
after proxy-chain exhaustion, and Apply requires private-window access because
Firefox proxy settings are global.

Chromium users install the published ZIP through **Load unpacked**. Firefox
154+ users install the Mozilla-signed XPI attached to the GitHub Release. There
is no public AMO listing for the new Gecko ID; unsigned reviewer artifacts are
not end-user downloads.
