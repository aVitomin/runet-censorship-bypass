# 1.0.1 — в подготовке

Эта страница описывает исходники следующего выпуска. Опубликованная версия
по-прежнему **1.0.0**; ссылки на установку находятся в
[пользовательской инструкции](../../user/INSTALLATION.md).

## Изменения

- Название: **Runet Censorship Bypass — Revived** / **Обход блокировок Рунета — Revived**.
  Идентификаторы расширений и существующие ссылки магазинов сохраняются.
- Светлая, тёмная и системная темы в настройках и всплывающем окне обоих
  браузеров. Переключатель расположен в шапке настроек; выбор сохраняется
  локально и не меняет маршрутизацию.
- В Firefox настройки разделены на переключаемые секции, добавлен поиск
  правил, поля подключения сворачиваются. Переход между секциями сохраняет
  черновик. Ошибка ввода открывает нужный раздел и поле.
- В Firefox уточнено описание режима «Автоматически» для ручного источника
  правил. Сохранение и применение настроек остаются отдельными действиями.
- Puppeteer обновлён до 25.15.0 с совместимыми зависимостями, устраняющими
  найденную уязвимость Zod. Эти инструменты используются только при разработке;
  production-зависимости не изменены.

## Совместимость и выпуск

Минимальная версия Firefox пока **154**. Проверка Windows на **153.5.1 ESR**
не заменяет проверку Debian/Linux; до её завершения поддержку ESR не заявляем.
Для воспроизведения подготовлен [отдельный сценарий](../qa/FIREFOX_ESR_153.md).

После проверки кандидата архивы и публикация выполняются по
[процессу выпуска](../RELEASE_PROCESS.md). Локальная сборка не является
подписанным магазинным пакетом; скриншоты и тексты магазинов должны
соответствовать окончательному кандидату.
