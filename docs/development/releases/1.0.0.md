Локальная итоговая проверка кандидата: 1128 тестов, проверки кода и обе сборки
прошли успешно. Подробные команды и сценарии: [тестирование](../TESTING.md).

| Браузер | Проверенный объём |
| --- | --- |
| Chrome 156.0.8078.47 | Поддерживаемый полный сценарий: маршрутизация, HTTP/HTTPS proxy authentication, восстановление после перезапуска, внешнее управление |
| Brave 156.1.98.60 / Chromium 156.0.8078.48 | Загрузка пакета, интерфейс, Apply, сохранённые неприменённые изменения, восстановление настроек после перезапуска, выключение |

В Brave после полного перезапуска тот же пакет повторно загружался в сохранённый
тестовый профиль. Это проверяет восстановление состояния, но не сохранение
магазинной установки. Firefox 1.0 не проверен как подписанная или магазинная
установка. Edge и остальные Chromium-форки не входили в эту матрицу 1.0.

Firefox 154.0 — заявленный минимум, а не свидетельство QA каждой версии,
платформы или ESR. Подписанный Firefox 0.0.4.0 ранее проверялся в Firefox 154.0.1;
это отдельный выпуск и отдельная проверка.

## Ограничения

- Chromium может перейти на Direct при некоторых ошибках PAC/браузера.
- Поддержка SOCKS-аутентификации зависит от браузера.
- Открытые соединения и кэш авторизации могут пережить Apply.
- Проверки не доказывают работу произвольных DNS, VPN, политик и прокси.
