# Установка, обновление и удаление

Версии для браузеров публикуются независимо.

| Браузер | Доступная версия | Где скачать |
| --- | --- | --- |
| Chromium | **1.0.0** | [GitHub Release v1.0.0](https://github.com/aVitomin/runet-censorship-bypass/releases/tag/v1.0.0) |
| Firefox | **0.0.4.0**, подписанный XPI | [GitHub Release v0.0.4.0](https://github.com/aVitomin/runet-censorship-bypass/releases/tag/v0.0.4.0) |
| Firefox 1.0 | Ожидает проверки Mozilla | Подписанный пользовательский пакет пока недоступен |

Chrome Web Store готовится отдельно. Пока используйте ZIP для Chromium.
Не устанавливайте автоматически созданные архивы **Source code** как расширение.

## Требования

Firefox требует версию **154.0 или новее**. Для Chromium отдельная минимальная
версия в манифесте не задана: нужен современный браузер с необходимыми MV3 API.
Поддержка всех Chromium-форков не гарантируется.

Для Chromium 1.0 выполнены следующие проверки:

| Браузер | Объём проверки |
| --- | --- |
| Chrome 156.0.8078.47 | Полный поддерживаемый браузерный сценарий: маршрутизация, авторизация прокси и восстановление |
| Brave 156.1.98.60, Chromium 156.0.8078.48 | Установка, открытие интерфейса, Apply, сохранённые неприменённые изменения, восстановление после перезапуска и выключение |

В проверке Brave после полного перезапуска тот же пакет повторно загружался
в сохранённый тестовый профиль. Восстановление настроек проверено; сохранение
магазинной установки после перезапуска ещё не проверялось. Edge и остальные Chromium-форки
отдельно в этой проверке 1.0 не участвовали.

Подписанный Firefox 0.0.4.0 ранее проверялся в Firefox 154.0.1.
Результаты относятся к указанным версиям и сценариям.

## Chromium: установить ZIP

### 1. Скачать и проверить

Скачайте [runet-censorship-bypass-mv3-1.0.0-9de66de.zip](https://github.com/aVitomin/runet-censorship-bypass/releases/download/v1.0.0/runet-censorship-bypass-mv3-1.0.0-9de66de.zip)
и [контрольную сумму](https://github.com/aVitomin/runet-censorship-bypass/releases/download/v1.0.0/runet-censorship-bypass-mv3-1.0.0-9de66de.zip.sha256.txt).

Ожидаемый SHA-256:

```text
0faa3e0208c9d8295d2216066184930ece89eddeae20d1d37e9ede0c2a1a48bb
```

В Windows можно проверить скачанный файл в PowerShell:

```powershell
Get-FileHash .\runet-censorship-bypass-mv3-1.0.0-9de66de.zip -Algorithm SHA256
```

Если значение отличается, не устанавливайте архив.

### 2. Распаковать и загрузить

1. Полностью распакуйте ZIP в постоянную папку.
2. Откройте страницу расширений:
   `chrome://extensions` в Chrome, `edge://extensions` в Edge
   или `brave://extensions` в Brave.
3. Включите **Режим разработчика / Developer mode**.
4. Нажмите **Загрузить распакованное расширение / Load unpacked**.
5. Выберите папку, в корне которой находится `manifest.json`.
6. Закрепите значок расширения на панели.

В других Chromium-браузерах используйте их раздел **Расширения / Extensions**.
Совместимые API ожидаются во многих таких браузерах, но это не подтверждение
проверки каждого из них.

Не перемещайте и не удаляйте выбранную папку: браузер продолжает читать её файлы.
Сторонний браузер или корпоративная политика могут ограничивать установку
распакованных расширений.

## Firefox: установить подписанный XPI

Для обычной установки пока доступен Firefox **0.0.4.0**:

1. Скачайте [runet-censorship-bypass-firefox-0.0.4.0-signed.xpi](https://github.com/aVitomin/runet-censorship-bypass/releases/download/v0.0.4.0/runet-censorship-bypass-firefox-0.0.4.0-signed.xpi).
2. Проверьте [контрольную сумму Firefox](https://github.com/aVitomin/runet-censorship-bypass/releases/download/v0.0.4.0/runet-censorship-bypass-firefox-0.0.4.0-signed.sha256.txt).
3. Откройте XPI в Firefox и подтвердите установку и разрешения.
4. В **Дополнения и темы → Расширения** выберите расширение и разрешите работу
   в приватных окнах. Это нужно для общей настройки прокси, в том числе
   при использовании обычных окон.
5. Закрепите значок расширения.

SHA-256 подписанного файла:

```text
c7e3042e48819644673db92b9150a9d54a551281046212d896a7f7202bc9c34c
```

Firefox 1.0 отправлен в Mozilla Add-ons и ожидает проверки. Пока нет подписанного
пакета, его нельзя предлагать как обычную установку. Не отключайте проверку
подписи и не заменяйте рабочую установку unsigned XPI.
Временная загрузка через `about:debugging` предназначена для разработки
и может исчезнуть после перезапуска браузера.

## Первый запуск

Для **1.0** откройте настройки, выберите источник, при необходимости настройте
подключение, нажмите **Сохранить настройки**, затем отдельно **Применить**.
Дождитесь показанного состояния; активность не означает проверку всех прокси.

Режим **Только мои правила и подключения** не требует автоматической базы.
Явному режиму **Прокси** нужно подходящее выбранное подключение.
Источники и локальные службы расширение не устанавливает и не запускает.

Для **Firefox 0.0.4.0** действия и названия кнопок отличаются. Следуйте
[руководству 0.0.4.0](USER_GUIDE.md), включая его ограничение редактирования.
Его автоматическим маршрутам нужна доступная локальная служба
Anticensority, Tor Browser или Tor.

[Настройка и повседневное использование версии 1.0](USER_GUIDE_1_0.md)

## Обновить расширение

### Chromium: сохранить ту же установку

1. Выключите маршрутизацию расширения перед заменой его файлов.
2. Скачайте новый ZIP из [Releases](https://github.com/aVitomin/runet-censorship-bypass/releases)
   и проверьте SHA-256.
3. Распакуйте архив во временную папку.
4. Полностью замените файлы внутри **той же постоянной папки**, которая уже
   загружена в браузер. Не смешивайте файлы разных версий.
5. На странице расширений нажмите **Перезагрузить / Reload** у существующей карточки.
6. Проверьте версию и сохранённые настройки, затем явно примените их.

Загрузка из другой папки может создать отдельную установку с другим хранилищем.
Не удаляйте прежнюю установку, рассчитывая на автоматический перенос настроек.
В 1.0 есть экспорт настроек, но он не включает пароли и не является полным
резервным снимком профиля.

### Firefox: использовать следующий подписанный выпуск

Устанавливайте следующий Mozilla-подписанный XPI с тем же идентификатором
расширения либо используйте опубликованную страницу AMO, когда она станет доступна.
После обновления проверьте версию, настройки и состояние маршрутизации.
Pending review не означает, что обновление уже доступно.

## Обновить данные или удалить расширение

Обновление данных маршрутизации в **Обслуживании** не устанавливает новую версию
расширения. В 1.0 оно сохраняет действующие пользовательские настройки
и не включает выключенную маршрутизацию. Подробнее — в
[руководстве 1.0](USER_GUIDE_1_0.md#обновить-данные-маршрутизации).

В Firefox **0.0.4.0** удалённое обновление базы отключено; встроенные данные
остаются доступны. Не переносите эту особенность на Firefox 1.0.

Для удаления сначала выключите маршрутизацию, затем удалите расширение
на странице расширений браузера. После удаления Chromium-карточки можно удалить
её постоянную папку. Расширение не очищает настройку, принадлежащую другой
программе или политике.

## English summary

Chromium **1.0.0** is available as a ZIP: verify its SHA-256, extract it
to a permanent folder, enable Developer mode, and select Load unpacked.
Update files in that same folder and reload the existing extension.

Firefox **1.0** is awaiting Mozilla review. The available signed fallback is
**0.0.4.0**; open its signed XPI in Firefox 154.0 or later and grant private-window
access. Never use an unsigned XPI as a normal installation.
Chrome Web Store publication is being prepared separately.

For version 1.0, Save records settings and Apply activates them.
Use the [1.0 guide](USER_GUIDE_1_0.md#english-summary), or the
[0.0.4.0 guide](USER_GUIDE.md) for that older version.
