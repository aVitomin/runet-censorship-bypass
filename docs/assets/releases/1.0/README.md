# Интерфейс версии 1.0

Снимки сделаны в настоящем установленном расширении из проверенных пакетов
`1.0.0`, без изменения интерфейса, ретуши или макетов. В примерах используются
только `news.example`, `proxy.example` и локальные тестовые подключения;
личных настроек и паролей нет.

Chromium снят в Chrome **156.0.8078.47**, Firefox — в **156.0.1**. Интерфейс
на снимках английский; расширение также поддерживает русский. Обе версии
**1.0.0** доступны в магазинах: [установка](../../../user/INSTALLATION.md).
Снимки сделаны при проверке кандидата и не являются отдельной проверкой магазинной установки.

## Настройки

Каждый снимок настроек имеет размер **1280 × 800**. Первые пять Chromium-снимков
подготовлены для карточки Chrome Web Store; наличие снимков не означает
публикацию в магазине.

| Сценарий | Chromium | Firefox |
| --- | --- | --- |
| Собственные правила применены; сохранённые настройки совпадают с активными | [Обзор](chromium/01-overview-active.png) | [Обзор](firefox/01-overview-manual-active.png) |
| Правило «Напрямую» для тестового сайта сохранено, но ещё не применено | [Правила сайтов](chromium/02-site-rule-saved-pending.png) | [Правила сайтов](firefox/02-site-rule-saved-pending.png) |
| Выбор источника маршрутизации | [Доступные источники](chromium/03-routing-source.png) | [Собственные правила и подключения](firefox/03-manual-routing-source.png) |
| Предпросмотр импорта; изменения ещё не подтверждены | [Предпросмотр](chromium/04-import-preview.png) | — |
| Собственное отключённое SOCKS5-подключение без пароля | [Подключения](chromium/05-own-proxy-connections.png) | — |
| Состояние установленной базы и управление обновлениями | — | [База маршрутизации](firefox/04-routing-data-status.png) |

**Активно** означает управление настройкой прокси браузера, а не проверенную
доступность подключения. Состояние установленной базы не обещает её свежесть;
снимок Firefox сохраняет фактическую дату источника.

## Панели у значка браузера

Обе панели действительно открыты у значка установленного расширения над
синтетической страницей `news.example`. Это не отдельно открытый HTML-документ.
Показано применённое правило **Напрямую / Direct** для одного хоста.

| Chromium: 407 × 480 | Firefox: 392 × 600 |
| --- | --- |
| ![Настоящая панель Chromium](chromium/06-native-popup.png) | ![Настоящая панель Firefox](firefox/05-native-popup-direct.png) |

Нативный размер сохранён; панели не растянуты до магазинного формата 1280 × 800.

## Происхождение файлов

[Метаданные и SHA-256](provenance.json) связывают каждый снимок с браузером,
сценарием и точным проверенным пакетом из
[успешной сборки основной ветки](https://github.com/aVitomin/runet-censorship-bypass-revived/actions/runs/40080389722).
Профили браузеров, вспомогательные программы съёмки и журналы сюда не включены.
Снимки и документация не входят в устанавливаемые пакеты расширения.

[Ранее подготовленная рекламная иллюстрация 440 × 280](../../store/chromium/promo-440x280.png)
использует тот же знак проекта; это иллюстрация, а не снимок продукта.
[Исторические снимки](../../store/README.md) сохраняются отдельно.
