# Документация Runet Censorship Bypass

Выберите руководство по версии установленного расширения.
Chromium **1.0.0** доступен в [GitHub Release v1.0.0](https://github.com/aVitomin/runet-censorship-bypass/releases/tag/v1.0.0).
Firefox **1.0** ожидает проверки Mozilla; доступная подписанная версия —
[Firefox 0.0.4.0](https://github.com/aVitomin/runet-censorship-bypass/releases/tag/v0.0.4.0).

Расширение выбирает маршруты браузера, но не предоставляет VPN или прокси.
Источники правил и ваши подключения определяют доступность соединения.
Firefox 1.0 и его снимки не являются инструкцией для старого подписанного XPI.

содержат прежние MV2 и магазинные инструкции. Они сохранены как история,
